\item

Escribe una expresión regular para cada inciso, con el siguiente alfabeto
$\Sigma = \{a,b,c\}$ que:

\begin{enumerate}[label=\alph*.]

    \item contengan un número \textbf{impar} de letras $a$
    (considerando desde $0$).

    \item tengan \textbf{longitud impar}.

    \item no contengan la subcadena $bb$.

\end{enumerate}

Da una expresión regular para todas las cadenas de letras en minúsculas
que contengan las cinco vocales en orden.
